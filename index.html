See it work

  • Maps the repo: finds entry points, builds a module map, a dependency graph, and lists the most important files.
  • Local-first: static analysis runs entirely on your machine and makes no network calls, enforced by egress checks in CI. The optional AI panel is the only outbound path, off unless you turn it on.
  • Guided walkthrough: gives you a "Start here" path through the code instead of a bare file tree.
